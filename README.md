## 🎯 المميزات الرئيسية

### 🔐 وحدة البصمات الرقمية
- حساب 4 أنواع من الهاش (MD5, SHA1, SHA256, SHA512)
- ضمان سلامة الأدلة وسلسلة الحضانة
- تقارير CSV قابلة للتصدير
- إحصائيات شاملة للملفات

### 🖼️ وحدة تحليل الصور
- استخراج بيانات EXIF الكاملة
- تحليل بالذكاء الاصطناعي (MobileNetV2)
- كشف إحداثيات GPS
- مؤشر الشك الجنائي التلقائي
- دعم رفع الصور الفردية أو مجلدات كاملة

### 🔎 وحدة البيانات الحساسة
- البحث عن أنماط Regex متقدمة:
  - عناوين البريد الإلكتروني
  - أرقام الهواتف
  - بطاقات الائتمان
  - عناوين IP
  - كلمات المرور المخزنة
- تقارير JSON تفاعلية
- رسوم بيانية لتوزيع الأنماط

### ⏳ وحدة الخط الزمني
- بناء خط زمني شامل للأحداث
- تتبع إنشاء/تعديل/وصول الملفات
- إعادة بناء سيناريو الحادث
- رسوم بيانية زمنية تفاعلية

## 🚀 التثبيت والتشغيل

### 1️⃣ تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

أو يدوياً:

```bash
pip install streamlit Pillow exifread numpy pandas plotly tensorflow
```

### 2️⃣ تشغيل التطبيق

```bash
streamlit run forensic_lab_interface.py
```

### 3️⃣ فتح المتصفح

سيتم فتح التطبيق تلقائياً على:
```
http://localhost:8501
```

## 🔧 التخصيص

### تغيير الألوان
عدّل قسم CSS في بداية الملف `forensic_lab_interface.py`:

```css
/* مثال: تغيير من الأحمر إلى الأخضر */
color: #00ff00;
text-shadow: 0 0 10px #00ff00;
```

### إضافة أنماط بحث جديدة
في دالة `search_sensitive_data`:

```python
patterns['Custom_Pattern'] = r'your_regex_here'
```
